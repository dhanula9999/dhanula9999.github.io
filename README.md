# Dhanula Digital World

A complete static personal website template.

## Files
- index.html
- style.css
- script.js

## Quick setup
1. Upload all three files to your GitHub Pages repository.
2. Keep the filenames exactly as they are.
3. Replace the demo photo/video cards with your own content.
4. Replace the placeholder social/contact links.
5. Commit/push changes and open your GitHub Pages URL.

The site includes Home, About, Story, Photos, Videos, Music, Education, Skills, Projects, Achievements, Travel, Memories, Journal, Ideas, Goals, Favorites, Business, Future, Bucket List and Contact.
